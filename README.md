# 꾹꾹 스텝 (Paw Paw Step) 🐾

고양이가 발판 위를 콩콩 뛰어다니는 **원버튼 리듬게임**입니다.
고양이가 다음 발판에 **착지하는 순간** 버튼을 꾹! 누르면 됩니다.

## 실행

빌드 과정 없이 바로 실행됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 (`index.html`을 바로 열어도 동작합니다).
`?auto`를 붙이면 자동 플레이(구경 모드)로 시작합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| Space / 아무 키 / 화면 터치 | 꾹! (박자 입력) |
| Esc | 일시정지 / 계속하기 |

## 규칙

- 판정: **Purrfect** ±45ms · **Nice** ±90ms · **Good** ±140ms. 그 밖은 Miss
- 고양이는 목숨이 9개! Miss 할 때마다 하나씩 줄어듭니다
- 랭크: S(95%↑) · A(88%↑) · B(75%↑) · C(60%↑) · D
- 밟을 때마다 멜로디 음이 나서, 잘 치면 곡이 완성됩니다

## 구조

```
index.html        화면(UI) 마크업
css/style.css     파스텔 UI 스타일
js/levels.js      레벨 데이터 + 고양이 스킨  ← 레벨 추가는 여기서
js/chart.js       path 문자열 → 발판 좌표/타이밍 변환
js/audio.js       Web Audio 합성 (음악, 효과음, 야옹)
js/game.js        세션: 판정, 점수, 목숨, 음악 스케줄링
js/render.js      캔버스 렌더링: 배경, 발판, 고양이, 이펙트
js/main.js        화면 전환, 입력, 저장, 게임 루프
```

## 레벨 만들기

`js/levels.js`의 `LEVELS` 배열에 항목을 추가하세요. 핵심은 `path` 문자열입니다.

| 토큰 | 의미 |
| --- | --- |
| `R` `L` `U` `D` | → ← ↑ ↓ 방향으로 한 칸 (1박) |
| `E` `Q` `Z` `C` | ↗ ↖ ↙ ↘ 대각선 |
| `R2`, `U0.5` | 박자 길이 지정 (2박, 반박) |
| `R*4` | 4번 반복 |
| `@160` | 이후부터 BPM 160으로 변경 |

```js
path: 'R*4 U*4 R0.5*8 @150 E*4 R*8'
```

음악은 `key`(으뜸음), `progression`(코드 진행), `melody`(밟을 때 나는 음)로 자동 합성됩니다.
