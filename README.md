# 꾹꾹 스텝 (Paw Paw Step) 🐾

몸이 쭈욱 늘어나는 고양이가 빙글빙글 돌며 발판을 건너는 **원버튼 리듬게임**입니다.
도는 끝이 다음 발판에 **닿는 순간** 버튼을 꾹! 누르면 됩니다.

## 실행

빌드 과정 없이 바로 실행됩니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속 (`index.html`을 바로 열어도 동작합니다).
`?auto`를 붙이면 자동 플레이(구경 모드)로 시작합니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| Space / 아무 키 / 화면 터치 | 꾹! (박자 입력) |
| Esc | 일시정지 / 계속하기 |

## 규칙: 쭈욱 늘어나는 고양이

- 고양이 한쪽 끝(엉덩이 또는 머리)이 발판을 밟고, 몸을 늘려 다른 끝을 **360° 빙글빙글** 돌립니다.
- 도는 끝이 **다음 발판에 닿는 순간** 누르면 앞발 ↔ 엉덩이가 번갈아 발판을 밟으며 나아갑니다.
- 도는 속도는 **1박에 180°로 일정**합니다. 그래서 길이 꺾인 각도가 곧 박자입니다.

| 길 모양 | 박자 |
| --- | --- |
| 직진 | 1박 |
| 안쪽 직각 | ½박 |
| 바깥쪽 직각 | 1½박 |
| 135° (뾰족) | ¼박 |
| 120° / 60° | ⅓박 / ⅔박 (셋잇단) |
| 🌀 빙글 발판 | 회전 방향이 반대로 |
| +N바퀴 발판 | N바퀴 더 돌고 착지 |

- 판정: **Purrfect** ±42ms · **Nice** ±80ms · **Good** ±120ms (촘촘한 구간은 비례해서 좁아짐)
- 판정 창보다 살짝 일찍 누르면 "너무 빨라!" → 콤보가 끊깁니다 (연타 방지)
- 목숨: 쉬움 9 · 보통 7 · 어려움 5 · 극악 3

| 난이도 | 곡 | BPM | 발판 | 특징 |
| --- | --- | --- | --- | --- |
| 쉬움 | 산책하는 오후 | 100 | 137 | 오르골 로파이, 직진과 직각 위주 |
| 보통 | 생선가게 탭댄스 | 124 | 222 | 펑키, 8분음표, 점8분(45°) |
| 어려움 | 달빛 지붕 위 | 140→152 | 276 | 신스팝, 셋잇단(120°/60°), 16분, 빙글 다수 |
| 극악 | 냥냥 대폭주 | 172→186 | 319 | 칩튠, 16분 연타, 빙글 지그재그 |

## 구조

```
index.html        화면(UI) 마크업
css/style.css     파스텔 UI 스타일
js/songs.js       노래 데이터 (코드, 드럼, 베이스, 멜로디, 채보 방식)  ← 곡 추가
js/levels.js      레벨 = 노래 + 난이도 + 테마, 고양이 스킨
js/chart.js       노래 컴파일 + 박자 → 발판 각도 배치 (겹침 방지 탐색)
js/audio.js       Web Audio 합성기 (벨, 플럭, 스퀘어, 칩튠, 패드, 베이스, 드럼, 리버브/딜레이)
js/game.js        세션: 판정, 점수, 목숨, 음악 스케줄링
js/render.js      캔버스 렌더링: 늘어나는 고양이, 발판, 이펙트
js/main.js        화면 전환, 입력, 저장, 게임 루프
```

## 노래/맵 만들기

`js/songs.js`에 곡을 추가하고 `js/levels.js`에 레벨로 등록합니다.
**채보는 노래에서 자동으로 만들어져요.** 섹션마다 `map`으로 발판을 어디에 놓을지 고르면,
그 리듬에 맞는 각도로 길이 자동으로 그려지고(겹치지 않게 빙글 발판을 섞어 줌) 음악과 박자가 항상 맞습니다.

```js
A: {
  bars: 8, chords: ['F', 'Dm', 'Bb', 'C'],
  drums: 'pop', bass: 'walk', pad: true,
  lead: 'C5:1 A4:.5 C5:.5 F5:1 E5:1 | ...',   // 음:박
  map: 'lead',      // 멜로디 음마다 발판
  twirl: 0.3,       // 빙글 발판 비율
},
```

| map | 의미 |
| --- | --- |
| `lead` | 멜로디 음마다 발판 |
| `beat` / `eighth` | 매 박 / 8분음표마다 |
| `every:3` | 3박마다 (고양이가 한 바퀴 더 돔) |
| `pat:1 .5 .5` | 박 길이 패턴 반복 |
